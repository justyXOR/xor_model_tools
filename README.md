# XOR's Model Tools
Utilities that will help you avoid baking repetitive normal and roughness maps. This addon includes standard textures, with more content planned for the future.

**Example usage in a VMT file:**
```
"$bumpmap" "xmdt/default_normalmap"        // Standard normal map
```
